## Sobre mim

Sou estudante do curso de Tecnologia em Análise e Desenvolvimento de Sistemas, com
conclusão prevista para o **primeiro semestre de 2027**. Desenvolvo aplicações de ponta
a ponta, com maior interesse por backend, APIs, modelagem de dados e regras de negócio.

Tenho experiência prática com **TypeScript, Node.js, PHP, Laravel, React, PostgreSQL e
Docker**. Nos meus projetos, trabalho com autenticação e autorização, bancos relacionais,
integrações entre frontend e backend, testes automatizados e ambientes conteinerizados.

Busco uma oportunidade de estágio para evoluir ao lado de uma equipe, aprender com
projetos em produção e contribuir com responsabilidade, curiosidade e vontade de resolver
problemas reais.

## Projetos em destaque

### 💼 [Jamval App](https://github.com/Mumurilo375/Jamval-App) — solução para uma operação real

**[Demonstração online](https://jamval-frontend.vercel.app/)** · Projeto individual

Sistema full stack criado para substituir controles em papel de uma pequena operação
familiar de vendas em consignação.

- Gerencia clientes, visitas, estoque, pagamentos, recebíveis e reposições.
- Coordena os efeitos de uma visita no estoque e no financeiro por meio de regras
  transacionais no backend.
- Gera comprovantes em PDF e apresenta indicadores financeiros e operacionais.
- Possui frontend e backend publicados na Vercel, com PostgreSQL no Supabase.

`React 19` · `TypeScript` · `Fastify` · `Prisma` · `PostgreSQL` · `Docker` · `Vercel`

---

### 🎮 [Nexus Full](https://github.com/Mumurilo375/nexusFull) — e-commerce web e mobile

Projeto acadêmico desenvolvido em dupla, com aplicações web e mobile consumindo a mesma
API e compartilhando regras de negócio e dados.

- Implementa autenticação JWT, catálogo, carrinho, checkout, pedidos e entrega de keys.
- Inclui painel administrativo para catálogo, estoque, promoções, pedidos e preços.
- Oferece experiências com React no navegador e React Native com Expo no celular.
- Possui testes com Vitest, Jest e Playwright, além de ambiente Docker com Nginx.

`React 19` · `React Native` · `Expo` · `TypeScript` · `Express` · `Sequelize` · `PostgreSQL` · `Docker`

---

### 🎨 [Scrapbook](https://github.com/Mumurilo375/scrapbook) — editor de presentes digitais

Projeto individual em desenvolvimento para criação, personalização, publicação e
compartilhamento de scrapbooks digitais interativos.

- Possui editor visual com canvas, camadas, transformações, histórico e autosave.
- Processa uploads e thumbnails em storage compatível com S3.
- Publica presentes por link e QR Code após um fluxo de checkout simulado.
- Utiliza monólito modular, versionamento de temas e modelos, analytics e painel
  administrativo.

`Laravel 13` · `React 19` · `TypeScript` · `Inertia.js` · `PostgreSQL` · `Redis` · `MinIO` · `Docker`

---

### 🍷 [Reserva Santanna](https://github.com/Mumurilo375/Reserva-Santanna) — e-commerce acadêmico

Projeto desenvolvido em equipe para simular a jornada de compra e a operação de uma
vinícola fictícia.

- Reúne catálogo, busca, carrinho, cotação de frete, checkout e pedidos simulados.
- Utiliza Laravel Sanctum para autenticação e separação entre cliente e administrador.
- Inclui dashboard, CRUD de produtos e controle de entradas e saídas de estoque.
- Integra frontend React, API Laravel e PostgreSQL em um ambiente Docker Compose.

`React 18` · `TypeScript` · `Laravel 12` · `Sanctum` · `PostgreSQL` · `Docker`
